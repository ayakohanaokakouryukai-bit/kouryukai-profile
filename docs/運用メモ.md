# 運用メモ

会の準備から終了後までの、困ったときの対応をまとめています。「データ用スプレッドシート」は、セットアップ手順の1で作ったものです。

## キャンセルの扱い

回答用スプレッドシートの「キャンセル」列に、何か入力します（○など）。その人は、専用URLの発行もログインもできなくなります。
一斉アクセスに強くするため、アプリは「どの合鍵が誰のものか」を5分間覚えています。そのため、キャンセルした本人の専用URLは、最長で5分間使えたままになります。他の参加者の一覧にも、最長で10分間表示されたままになることがあります。

すぐに反映したいときは、次の手順で操作します。

1. GASのエディタを開きます。
2. 左のファイル一覧で `Main.gs` を開きます。
3. 関数の選択欄で `applyCancellationsNow` を選び、「実行」を押します。

実行すると、本人の専用URLも一覧の表示も、その場で反映されます。
同じメールアドレスで回答が複数行ある場合は、すべての行に入力してください（1行でも空だと、登録できる状態のままになります）。

## メールが届かない人

1. 迷惑メールフォルダを確認してもらうようお願いします。
2. それでも届かないときは、データ用スプレッドシートの `tokens` シートで、その人のメールアドレスの行を探し、`url` 列をコピーして、LINEなどで本人に直接送ります。

## 専用URLの作り直し（URLが漏れたとき）

1. `tokens` シートで、その人の行の `token` と `url` を空にします（行は消さず、この2つのセルだけ消します）。続けて、上の「キャンセルの扱い」と同じ手順で `applyCancellationsNow` を実行します（実行しないと、古いURLが最長5分間使えたままになります）。
2. 本人に、登録ページでメールアドレスをもう一度入力してもらいます。新しいURLがメールで届きます。
   メールを送れるのは、同じアドレスに1日1回までです。その日すでに送っていた場合は、翌日にお願いしてください。

## スタッフの印

`profiles` シートで、その人の行の `staff` 列に「○」を入れます。一覧への反映は、最大10分かかります。

## メールアドレスの打ち間違い

回答用スプレッドシートの、メールアドレスを直します。

## 送信待ちの確認

`tokens` シートの `pending` が `TRUE` の行は、メールがまだ送れていない人です。1時間ごとに自動で送り直されます。ただし、その日すでにメールを送った人の行は、翌日まで `TRUE` のままです。
1日に送れるメールは100通までです。残りが10通を切ると、運営のアドレスに知らせのメールが届きます。

## 案内の出し方

- 登録ページの案内は、一斉に出さず、数回に分けて出してください（1日に送れるメールが100通までのためです）。
- 会の数日前に、「一度、参加者一覧を開いておいてください」と案内してください。当日、全員が同時に開くと表示が遅くなることがあるためです。

## やってはいけないこと

- 会の期間中に、`tokens` シートと `profiles` シートで、並べ替え・行の挿入・列名の変更をしないでください。動かなくなります。
- データ用スプレッドシートと写真用フォルダを、誰とも共有しないでください。全員の専用URLが載っています。

## 会が終わったあと（2027-05-06以降）

- 2027-05-06 を過ぎると、専用URLは自動で使えなくなります。
- そのあと、データ用スプレッドシートと写真用フォルダを、手作業で削除してください（自動では消えません）。
- 回答用スプレッドシート（フォームの回答）をどうするかは、別途ご判断ください。

## 本番前の確認

### 同時アクセスのテスト

100人が同時に一覧を開いても動くかを確かめます。

1. データ用スプレッドシートの `tokens` シートで、自分の行の `token` をコピーします。ただし、自分のプロフィールで、公開に同意して必須項目を入力済みにしておく必要があります（一覧が開けない状態だと、すべて失敗になります）。
2. ターミナルで、アプリのフォルダに移動します（`cd ` と入力してFinderからフォルダをドラッグすると場所が入ります）。

```bash
cd <profile-appフォルダの場所>
```

3. 次を入力します（`<ウェブアプリのURL>` と `<合鍵>` は置き換えます）。

```bash
node tools/loadtest.mjs --url <ウェブアプリのURL> --token <合鍵> --n 100
```

結果は `ok=100 failed=0 p50=... p95=... max=...` のように表示されます（単位はミリ秒）。

合格ライン：`failed=0`、かつ `p95` が 10000（10秒）以内。

### 数式・自動変換の確認

プロフィールに入力した文字が、スプレッドシートで数式や数字に変わらないことを確認します。

1. 自分の専用URLで、「今やっていること」などに、次を1つずつ入力して保存します：`=1+1`、`=A2`、`3/4`、`007`、`50%`
2. データ用スプレッドシートの `profiles` シートを開きます。

うまくいくと：入力したとおりの文字のまま（`=1+1` が `2` になっていない、`007` が `7` になっていない、`3/4` が日付になっていない、`50%` が `0.5` になっていない）表示されます。
