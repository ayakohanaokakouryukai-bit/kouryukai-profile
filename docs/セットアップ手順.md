# セットアップ手順

はじめてアプリを公開するときの手順です。上から順に進めてください。ターミナル（Macのアプリ）では、書かれたとおりに入力して Enter を押します。

使うアカウント
- Google：`ayako.hanaoka.kouryukai@gmail.com`
- GitHub：同じメールアドレスで作ったアカウント（以下、ユーザー名を `<GitHubのユーザー名>` と書きます）

## 事前に必要なもの

次の3つが入っているか、ターミナルで確認してください。入っていない場合は、案内に従ってインストールしてください。

1. Node.js：次を入力して、バージョンが表示されれば大丈夫です。

```bash
node -v
```

2. clasp（Google Apps Script を操作する道具）：次を入力してインストールします。

```bash
npm install -g @google/clasp
```

インストールできたかは、次で確認します。

```bash
clasp --version
```

3. GitHub CLI（gh）：https://cli.github.com からインストールしてください。インストールできたかは、次で確認します。

```bash
gh --version
```

## 1. 保存場所を作る（Googleドライブ）

1. 交流会のGoogleアカウントでログインします。
2. Googleドライブで、新しいスプレッドシートを作ります。名前は「交流会プロフィール_データ」など、わかりやすいものにします。これが「データ用スプレッドシート」です。
3. 同じくドライブで、新しいフォルダを作ります。名前は「交流会プロフィール_写真」など。これが「写真用フォルダ」です。
4. IDを控えます。
   - データ用スプレッドシートを開き、アドレスバーのURL `https://docs.google.com/spreadsheets/d/ここがID/edit` の「ここがID」の部分を、メモ帳などに控えます（`DATA_SHEET_ID`）。
   - 写真用フォルダを開き、URL `https://drive.google.com/drive/folders/ここがID` の「ここがID」を控えます（`PHOTO_FOLDER_ID`）。
5. 回答用スプレッドシート（参加申込フォームの回答が入っているもの）のIDも、同じ方法で控えます（`FORM_SHEET_ID`）。

重要：データ用スプレッドシートと写真用フォルダは、誰とも共有しないでください。全員の専用URLが載っているためです。共有ドライブにも入れないでください。

うまくいくと：メモ帳に、3つのIDが控えられています。

## 2. 回答シートに「キャンセル」列を足す

1. 回答用スプレッドシートを開き、回答が入っているシート（下のタブ。例：フォームの回答 1）を開きます。
2. 1行目（見出しの行）の一番右の空いているセルに「キャンセル」と入力します。
3. 見出しの文字とタブ名を控えます。メールアドレスの列の見出しの文字（`EMAIL_HEADER`）と、タブ名（`FORM_SHEET_NAME`）です。

うまくいくと：見出し行の右端に「キャンセル」と表示されます。その下は空のままで構いません。

## 3. コードをGoogleに送る（clasp）

clasp（クラスプ）は、パソコン上のコードをGoogle Apps Script（GAS）に送る道具です。

### 3-1. Apps Script API をオンにする

1. 交流会のGoogleアカウントでログインしたまま、次のURLを開きます：https://script.google.com/home/usersettings
2. 「Google Apps Script API」をオンにします。

うまくいくと：スイッチが「オン」の状態になります。

### 3-2. ログインする

ターミナルを開き、アプリのフォルダ（`profile-app`）に移動します。`cd ` と入力してからFinderでそのフォルダをターミナルにドラッグすると、場所が入力されます。

```bash
cd <profile-appフォルダの場所>
```

```bash
clasp login
```

ブラウザが開くので、交流会のアカウント（ayako.hanaoka.kouryukai@gmail.com）を選び、「許可」を押します。

うまくいくと：ターミナルに「Authorization successful.」と出ます。

### 3-3. プロジェクトを作って送る

```bash
cd gas
```

```bash
clasp create --type standalone --title "100人交流会 参加者プロフィール"
```

うまくいくと：「Created new standalone script」とURLが表示され、`gas` フォルダに `.clasp.json` ができます。

claspが `appsscript.json` を上書きしてしまうことがあります。元に戻すため、次を入力します。

```bash
git checkout appsscript.json
```

```bash
clasp push
```

もし「Manifest file has been updated. Do you want to push and overwrite?」と聞かれたら `y` と入力して Enter。

うまくいくと：「Pushed 9 files.」のように表示されます（数字は多少違っても構いません）。

## 4. GASの設定を入れる

1. ターミナルで次を入力すると、GASのエディタがブラウザで開きます。

```bash
clasp open-script
```

2. 左の歯車「プロジェクトの設定」を押し、一番下の「スクリプト プロパティ」の「スクリプト プロパティを追加」を押します。「スクリプトプロパティ」とは、このアプリだけが読める設定メモのことです（IDのような秘密の値をここに置きます）。
3. 次の9つを、「プロパティ」と「値」に入力します。入力が終わったら「スクリプト プロパティを保存」を押します。

| プロパティ | 値（例） |
|---|---|
| `FORM_SHEET_ID` | 回答用スプレッドシートのID（URLの `/d/` と `/edit` の間） |
| `FORM_SHEET_NAME` | 回答のタブ名。例：`フォームの回答 1` |
| `EMAIL_HEADER` | 回答シートのメールアドレス列の見出しを、そのまま |
| `CANCEL_HEADER` | `キャンセル` |
| `DATA_SHEET_ID` | データ用スプレッドシートのID |
| `PHOTO_FOLDER_ID` | 写真用フォルダのID（URLの `/folders/` の後ろ） |
| `APP_BASE_URL` | 例：`https://<GitHubのユーザー名>.github.io/<リポジトリ名>`（最後にスラッシュを付けない）。手順6が終わってから正しい値に直します。今は仮の値で構いません |
| `ORGANIZER_EMAIL` | `ayako.hanaoka.kouryukai@gmail.com` |
| `EXPIRES_AT` | `2027-05-06T23:59:59+09:00`（専用URLの使える期限） |

うまくいくと：9行が一覧に並びます。

4. 左の「エディタ」（`<>` のマーク）に戻ります。左のファイル一覧で `Store.gs` を開き、上の関数の選択欄で `setupDataSheet` を選び、「実行」を押します。この関数は、データ用スプレッドシートに `tokens` と `profiles` の2つのシートを作ります。

初回は権限の確認が出ます。自分で作ったスクリプトでは普通に出る画面で、危険ではありません。
- 「権限を確認」を押す → アカウントを選ぶ → 「詳細」を押す → 「（プロジェクト名）（安全ではないページ）に移動」を押す → 「許可」を押す。

うまくいくと：画面下の実行ログに「実行完了」と出て、データ用スプレッドシートに `tokens` と `profiles` のタブが増えています。

5. 左のファイル一覧で `Main.gs` を開き、関数の選択欄で `setupTriggers` を選び、「実行」を押します。これは、送信待ちのメールを1時間ごとに自動で送り直す設定です。

うまくいくと：「実行完了」と出ます。左の時計マーク「トリガー」を開くと、`processPendingTrigger` が「時間主導型」で1つ登録されています。

## 5. ウェブアプリとして公開する（デプロイ）

「デプロイ」とは、GASを外から呼べる状態で公開することです。

1. GASエディタ右上の「デプロイ」→「新しいデプロイ」を押します。
2. 「種類の選択」の歯車から「ウェブアプリ」を選びます。
3. 「次のユーザーとして実行」は「自分」、「アクセスできるユーザー」は「全員」にします。
4. 「デプロイ」を押します（権限の確認が出たら手順4と同じ要領で許可します）。
5. 表示された「ウェブアプリ」のURLをコピーします。
6. このフォルダの `web/js/config.js` を開き、`REPLACE_AT_SETUP` の部分を、コピーしたURLに書き換えます。

```js
export const GAS_URL = 'コピーしたURL';
```

確認：コピーしたURLをブラウザで開くと、`{"ok":true}` と表示されます。

うまくいくと：ブラウザに `{"ok":true}` と出ます。

## 6. 画面を公開する（GitHub Pages）

1. GitHub（https://github.com）に交流会のアカウントでログインし、右上の「+」→「New repository」を押します。
2. 名前を付け（`<リポジトリ名>`）、「Public」（公開）を選びます。「Add a README file」などのチェックは入れず、「Create repository」を押します。
3. 先に公開の方式を決めます。作ったリポジトリの「Settings」→ 左の「Pages」→「Build and deployment」の「Source」を「GitHub Actions」にします。（この設定を先にしておかないと、次の公開が失敗します。）
4. ターミナルでGitHubにログインします。

```bash
gh auth login
```

質問には次のように答えます（矢印キーで選び、Enter）。
- 「What account do you want to log into?」→ `GitHub.com`
- 「What is your preferred protocol for Git operations?」→ `HTTPS`
- 「Authenticate Git with your GitHub credentials?」→ `Yes`
- 「How would you like to authenticate GitHub CLI?」→ `Login with a web browser`

画面に出る8文字のワンタイムコードをコピーして Enter を押すとブラウザが開きます。交流会のGitHubアカウントでログインし、コードを貼り付けて許可します。このMacで別のGitHubアカウントにすでにログインしている場合は、先に `gh auth logout` を実行するか、交流会のアカウントを選んでください。

うまくいくと：ターミナルに「Logged in as <GitHubのユーザー名>」と出ます。

5. アプリのフォルダ（`profile-app`）に移動します。`cd ` と入力したあと、Finderで `profile-app` フォルダをターミナルのウィンドウにドラッグすると、場所が自動で入力されます。そのまま Enter を押します。

```bash
cd <profile-appフォルダの場所>
```

6. 次を1つずつ入力します。

```bash
git add web/js/config.js
```

```bash
git commit -m "chore: set GAS url"
```

```bash
git remote add origin https://github.com/<GitHubのユーザー名>/<リポジトリ名>.git
```

```bash
git push -u origin main
```

7. GitHubのリポジトリの「Actions」タブを開き、緑のチェックが付くまで待ちます（1〜2分）。赤い✗が出たときは、「Actions」タブ → 失敗した実行 → 「Re-run all jobs」（または左の「Deploy web to GitHub Pages」→「Run workflow」）で再実行します。
8. 「Settings」→「Pages」に表示されたURLをコピーします。例：`https://<GitHubのユーザー名>.github.io/<リポジトリ名>`
9. GASのスクリプトプロパティ `APP_BASE_URL` を、このURL（最後のスラッシュなし）に書き換えて保存します。

うまくいくと：そのURLをブラウザで開くと、登録ページ（メールアドレスの入力欄）が表示されます。試すアドレスは、すでに回答用スプレッドシートに載っているものにしてください（先に自分でフォームに回答しておきます）。「キャンセル」列が空であることも確認します。専用URLのメールが届けば成功です。

## 7. コードを直したときの再デプロイ

URLを変えずに、新しいコードに入れ替える方法です。

1. ターミナルで、`profile-app` フォルダの中の `gas` フォルダに移動します（`cd ` と入力して、Finderから `gas` フォルダをターミナルにドラッグすると場所が入ります）。

```bash
cd <profile-appフォルダの場所>/gas
```

```bash
clasp push
```

2. GASエディタで「デプロイ」→「デプロイを管理」を押します。
3. 今のデプロイの右にある鉛筆（編集）を押します。
4. 「バージョン」を「新バージョン」にして「デプロイ」を押します。

注意：「新しいデプロイ」を選ぶとURLが変わってしまいます。必ず「デプロイを管理」から編集してください。

うまくいくと：URLは同じまま、新しいコードが動きます。画面側（`web/`）を直したときは、`main` に push するだけで自動的に公開し直されます。

このMacでは GitHub CLI の普段のアカウントが別のため、push は次のように交流会アカウントのトークンを指定して行います（`profile-app` フォルダで実行）。

```bash
GH_TOKEN=$(gh auth token -h github.com -u ayakohanaokakouryukai-bit) git push origin main
```
