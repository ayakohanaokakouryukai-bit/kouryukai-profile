# 100人交流会 参加者プロフィール

交流会の参加者が、自分のプロフィールを登録し、公開に同意した人どうしで一覧を見られるWebアプリです。

- 画面（`web/`）はGitHub Pagesで公開します。
- データはGoogleスプレッドシートに、処理はGoogle Apps Script（GAS）に置きます。
- 参加者は、登録ページでメールアドレスを入力すると、自分専用のURLがメールで届きます。

## フォルダ構成

| フォルダ | 内容 |
|---|---|
| `gas/` | Google Apps Script のコード（API、メール送信、シート操作） |
| `web/` | 画面（登録ページ、マイページ、参加者一覧） |
| `test/` | 自動テスト |
| `tools/` | 負荷テスト用のツール（`loadtest.mjs`） |
| `docs/` | 手順書 |
| `.github/workflows/` | GitHub Pagesへ公開する設定 |

## テスト

```bash
npm test
```
